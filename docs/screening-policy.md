# 文献筛选规则 · 2026-11-04 修订

## 优先级

优先整理医疗算法公平性的原始方法学：评估设计、公平指标、基准、偏差机制，以及 pre-/in-/post-processing 缓解方法。有明确医疗任务、分组和测量的原始公平性审计同样可以纳入，不要求一定提出新算法或获得正向结果。

综述、观点和编辑评论在候选排序中降权，不设置未经维护者指定的固定收录比例。一般稳健性、类别不平衡、跨中心迁移或健康差异本身，不自动等同于算法公平性。

## 综述的必要门槛

综述必须同时满足：

1. 指向具体疾病或医疗任务，例如卒中影像诊断、心血管风险预测或特定临床决策任务。
2. 对该场景中的算法公平性作实质而详细的分析，例如讨论明确亚组、指标、偏差机制、具体评估框架或缓解方法的比较。

两项均需原文证据，不能仅凭标题或 fairness/bias 关键词匹配。只在伦理、治理、实施障碍中顺带列举公平性的问题不进入收录建议；非医疗 AI 文献也不进入主目录候选推荐。访问不足、无法判断分析深度的文章保留待核验，不把“摘要没写”解释为“全文没有”。

综述可以通过系统比较已有证据满足分析要求，不要求综述作者再做原创实验；摘要与 TLDR 必须准确标注综述或评论性质。

## 机器筛选与人工审核

规则版本为 `2-methodology-first`。模型输出文章类型，并分别给出“具体医疗任务”和“详细公平性分析”的短原文证据。验证器拒绝将不满足两项要求的综述标为收录建议或相关推荐。机器收录建议仍要求全文证据；最终加入 README 必须有维护者明确批准。

维护者提交的审核单支持“纳入”和“通过”两个等价决定。人工批准可以覆盖机器的初筛建议；此时仍核对原始记录及可用摘要/全文，如实标注证据层级，保存覆盖原因。人工纳入某篇评论或医疗图像代表性审计，不意味着未来所有评论或代表性研究自动获得资格。

`data/curation-decisions.json` 保存文章编号、决定、备注、审核证据版本和文章内容版本。已排除且内容未变的条目不重复调用模型，也不重复出现在下一周审核单；已收录文章同样不再送审。模型提示版本变化不会抹掉人工决定。文章自身出现实质更新时，重新核验内容，不沿用旧的纳入批准。
